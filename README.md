# 高速动车组弓网系统振动特性研究

**简体中文** · [English](./README.en.md)

北京交通大学 · 车辆工程本科毕业设计 · 2026 年 5 月

轨道不平顺引起的车体振动，会怎样改变受电弓与接触线之间的接触力？本研究先用 SIMPACK 计算车体的垂向运动，再将位移和速度输入 Simulink 中的 DSA380 型受电弓三质量模型与变刚度接触网模型，分析运行速度、轨道质量和受电弓悬挂参数对受流质量的影响。

## 仿真结果

在 250 km/h 下，从无轨道干扰到高干扰，平均接触力只下降了约 2 N，最小接触力却下降了约 20 N。仅看平均值，容易忽略弓头与接触线之间压力最低的瞬间。下表数据取自[论文表 3-2](./高速动车组弓网系统振动特性研究.pdf#page=31)。

| 接触力指标 | 无干扰 | 低干扰 | 高干扰 |
| --- | ---: | ---: | ---: |
| 平均值（N） | 155.86 | 156.82 | 153.78 |
| 标准差（N） | 48.62 | 50.56 | 55.85 |
| 最小值（N） | 73.01 | 61.67 | 52.56 |

论文第 4 章还比较了 225–350 km/h 的六个速度工况。针对受电弓悬挂参数的 L9 正交试验显示，在所考察的参数范围内，下框架阻尼 `c3` 对接触力标准差的影响最大，其次是弓头刚度 `k1` 和上框架刚度 `k2`。

## 运行 Simulink 模型

1. 在 MATLAB 中将当前文件夹切换到仓库目录。模型保存于 Simulink R2026a，以下零输入示例已在该版本中运行验证。
2. 将 [MATLAB 工作区代码](./matlab工作区代码.md)的第一段复制到 MATLAB 命令窗口并运行。示例速度为 `v_kmh = 250`，静态抬升力为 `F0 = 70` N。
3. 首次运行可将车体垂向速度和位移设为零，检查模型和输出。以下输入覆盖模型默认的 10 s 仿真时长。

   ```matlab
   body_vel = [0 0; 10 0];  % 每行依次为时间 (s)、垂向速度 (m/s)
   body_pos = [0 0; 10 0];  % 每行依次为时间 (s)、垂向位移 (m)
   out = sim('PC_model');
   ```

4. 在 `out.contact_force` 中查看接触力（N），在 `out.x1`、`out.k_t` 和 `out.dis` 中分别查看弓头位移（m）、接触网刚度（N/m）和运行距离（m）。

**复现论文中的轨道激励工况。** 需要另行提供对应工况的 SIMPACK 车体垂向速度和位移时程。仓库中未附 SIMPACK 整车工程及其导出数据。

1. 将工作区代码第二段中的两处 `readmatrix('.txt')` 分别指向速度文件和位移文件。两份文件的第一列均为时间（s），第二列分别为速度（m/s）和位移（m）。
2. 运行 `clear body_vel body_pos`，再执行第二段代码，将时程载入模型使用的两个输入变量。随后重新运行 `out = sim('PC_model')`。

**导出 Excel。** 接触力、弓头位移和刚度每 1 ms 记录一次，`out.tout` 和 `out.dis` 使用求解器的时间点。使用第三段导出示例时，将 `time` 和 `s` 的赋值替换为以下两行，使每个力值都对应同一时刻的运行距离。这里的 `v` 是模型使用的恒定车速（m/s）。

```matlab
time = (0:numel(out.contact_force)-1)' * 1e-3;
s = v * time;
```
